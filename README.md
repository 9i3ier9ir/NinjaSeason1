# NinjaSeason1

A browser-based ninja adventure game inspired by the legend of Kaelen and the Prism Edge.

## Features

- Start menu with Play, Weapons, Items, Levels, Save, Load, and Credits
- Pause menu with Resume, Save, and return to Main Menu
- Manual save/load system using browser localStorage
- Narrative-driven levels based on the story
- Cinematic cutscenes before each major trial
- Animated themed environments and upgraded canvas art
- Weapon progression through elemental trials
- Simple canvas-based combat with movement, attack, and enemy encounters

## How to play

1. Open `index.html` in a browser.
2. Use Arrow keys or WASD to move.
3. Press `Space` to attack.
4. Press `E` to switch weapons.
5. Press `Esc` to open the pause menu.
6. Use Save and Load to preserve progress manually.

## Files

- `index.html` — game UI and menu structure
- `styles.css` — visual styling for menus and game canvas
- `game.js` — game logic, save system, and canvas rendering

Enjoy the journey through the Valley of Whispers and unlock Kaelen’s elemental powers.
